# Contributing

Thanks for helping. To add a room:

1. Fork the repo and edit `README.md`.
2. Add the room under the right phase: `- [ ] [TryHackMe | Name](https://tryhackme.com/room/slug) — one-line description`
3. Confirm the room is **free** (no subscriber lock) and not already listed (search the slug).
4. Open a pull request. Contributors are credited automatically.

Found a room that went premium? Open an issue and we'll move it to "No Longer Free".
